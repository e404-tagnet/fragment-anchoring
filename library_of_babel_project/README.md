# Library of Babel Clone

A configurable Python project with a shared core module and a Flask web app.

## Files
- `app.py`
- `library_of_babel_core.py`
- `templates/`
- `README.md`

## Run
```bash
pip install flask
python app.py
```

## Features
- Search by text
- Browse by address
- Snippet search
- Random page generation
- Config page
- Download saved text file
